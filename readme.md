# Savorix 🌴✈️

**Savorix Holidays** is a simple and attractive travel website created using HTML and CSS. It showcases holiday packages for popular destinations and provides useful travel tips for visitors.

## 🌍 Features

- **Header Section:** Displays the brand name and tagline.
- **Navigation Bar:** Includes Home, Packages, and Contact sections.
- **Holiday Packages:** Showcases Goa and Kashmir tour packages with images, descriptions, and starting prices.
- **Why Choose Us:** Highlights affordable tour packages, comfortable hotels, experienced guides, and customer support.
- **Travel Tips:** Provides helpful tips for a comfortable and safe journey.
- **Footer Section:** Displays the brand name, travel tagline, and copyright information.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html`, `style.css`, and both destination images are in the correct locations.
4. Open `index.html` in your browser to view the website.

## 🎯 Project Objective

The objective of this project is to practice HTML page structure and CSS styling while creating a travel website that presents holiday packages in a clear and organized layout.
